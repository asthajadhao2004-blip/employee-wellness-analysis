# Employee Wellness Analysis

## Project Overview

This project explores employee mental health survey data to understand patterns associated with mental health treatment-seeking and workplace support.

The analysis was conducted using Python and Exploratory Data Analysis (EDA) to identify patterns in demographics, workplace factors, employer support, and employee attitudes.

## Business Objective

To identify gaps in mental health support and provide data-informed recommendations that organisations can use to improve employee wellness programmes.

## Dataset

- 1,048 survey responses
- 28 attributes
- Target variable: `treatment` (Yes/No)

The dataset includes demographic details, workplace conditions, employer benefits, family history, and attitudes towards mental health.

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Statistical analysis and data visualisation

## Project Workflow

1. Data inspection and quality assessment
2. Handling missing values and duplicate records
3. Cleaning age, gender, and company-size categories
4. Exploratory data analysis
5. Comparing treatment-seeking across employee groups
6. Analysing associations between workplace factors and treatment
7. Developing business recommendations

## Key Findings

- 48.9% of respondents reported having sought mental health treatment.
- Family history was associated with a higher treatment-seeking rate.
- Awareness of employer benefits and care options was associated with higher treatment-seeking.
- Work interference showed a strong association with treatment-seeking.
- Company size did not show a statistically significant difference in treatment-seeking in this analysis.

These findings describe associations and do not establish causation.

## Business Recommendations

- Improve communication about mental health benefits and care options.
- Train managers to respond supportively to employee concerns.
- Encourage proactive wellness check-ins.
- Provide confidential channels for seeking help.
- Validate findings using the organisation's own employee data.

## Project Files

- `Employee_Wellness_EDA.ipynb` — Jupyter Notebook containing the analysis and visualisations.
- `Employee_Wellness_Analysis.pptx` — PowerPoint presentation summarising the findings and recommendations.

## Limitations

The analysis uses self-reported survey data. The sample is not necessarily representative of every organisation, and some demographic groups have small sample sizes. Associations should not be interpreted as proof of cause and effect.

## Conclusion

This project demonstrates how data cleaning, exploratory analysis, statistical comparisons, and visualisation can help translate survey data into practical business recommendations for employee wellness.
